사이트 접근 권한 (선택)

기본적으로 Image Hunter는 메뉴를 연 탭에만 일시적으로 접근합니다(activeTab). 아래 권한을 허용하면 다음이 가능해집니다.

  • 다른 사이트(CDN)에 있는 이미지의 실제 파일 크기·형식 확인
  • 다른 사이트 이미지를 PDF에 넣기
  • 페이지 안 다른 사이트 iframe의 이미지 추출
