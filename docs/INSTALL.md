# Image Hunter 설치 및 사용 설명서 (v1.0.0)

웹페이지에서 썸네일이 아닌 **원본 이미지**를 찾아 차례로 확인하고, 골라서 한꺼번에 내려받는 Chrome 확장 프로그램입니다. 서버 없이 내 PC에서만 동작합니다.

- 지원 환경: Windows 11, Chrome 116 이상 (Manifest V3)
- 외부 서버 전송 없음 — 모든 분석은 브라우저 안에서 처리됩니다.

---

## 1. 설치

1. `image-hunter-1.0.0.zip` 파일의 압축을 풉니다.
   예: `C:\Tools\image-hunter-1.0.0\` (이 폴더 안에 `manifest.json`이 있어야 합니다)
2. Chrome 주소창에 `chrome://extensions` 를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다** 를 누르고 1번에서 압축을 푼 폴더를 선택합니다.
5. 툴바의 퍼즐 아이콘에서 **Image Hunter** 옆 핀을 눌러 고정합니다.

> 압축을 푼 폴더를 지우거나 옮기면 확장 프로그램이 동작하지 않습니다. 업데이트할 때는 같은 폴더에 새 파일을 덮어쓴 뒤 `chrome://extensions` 에서 새로고침(↻)을 누르세요.

### 권한 안내

| 권한 | 사용 목적 |
| --- | --- |
| 모든 사이트 접근 | 페이지의 이미지 목록 수집, 원본 후보의 실제 해상도·크기 확인 |
| 다운로드 | 일괄 다운로드, 파일명·폴더 지정 |
| 스크립팅 / 탭 | 분석할 탭에 수집 스크립트 실행, 스크롤 재탐색 |
| 저장소 | 설정 저장, 다운로드 대기열 유지 |
| 요청 헤더 수정 | 외부 링크를 막는 사이트를 위해 이미지 요청에 원래 페이지 주소(Referer) 지정 |

## 2. 페이지 분석

1. 이미지를 받을 페이지를 엽니다.
2. 툴바의 Image Hunter 아이콘을 누르거나 **Alt + Shift + I** 를 누릅니다.
3. 새 탭에 분석 화면이 열리고 이미지 수집과 **원본 판별**이 자동으로 진행됩니다.

### 원본 판별 방식

이미지마다 원본이 될 수 있는 주소를 모두 모은 뒤, 실제로 파일 앞부분을 읽어 **진짜 해상도**를 확인하고 가장 큰 것을 고릅니다.

| 우선순위 | 후보 출처 |
| --- | --- |
| 1 | `srcset` / `<picture>` 의 가장 큰 후보 |
| 2 | 이미지를 감싼 링크, `data-full`·`data-zoom-image` 같은 고해상도 속성 |
| 3 | 썸네일 규칙을 되돌린 변형 URL (`-300x200`, `_thumb`, `/thumbs/`, `?w=300`, `name=small` 등) |
| 4 | 화면에 표시된 이미지 주소 |
| 5 | 해상도를 확인할 수 없는 주소 |

- URL 문자열만으로 원본이라고 단정하지 않습니다. 변형 URL과 링크는 **실제로 존재하고, 표시된 이미지와 가로세로 비율이 같을 때만** 채택합니다.
- 각 카드에는 해상도 · 형식 · 파일 크기(확인된 경우만)와 함께 다음 표시가 붙습니다.
  - **원본 높음 / 보통 / 확인 필요**: 원본일 가능성(신뢰도)
  - **원본 발견**: 화면에 보이는 것보다 큰 원본을 찾아 확인함
  - **원본 후보 없음**: 해상도를 확인할 수 있는 주소가 하나도 없음
  - **썸네일 의심**: 크기가 작거나(기본 300px 미만) 주소가 썸네일 형태인데 더 큰 버전을 못 찾음
  - 출처: `srcset`, `링크`, `변형 URL`, `CSS 배경` 등
- 같은 원본으로 이어지는 썸네일과 원본은 하나로 합쳐집니다(중복 제거).

### 스크롤 후 재탐색

스크롤해야 이미지가 나타나는 페이지(웹툰, 무한 스크롤 등)는 **스크롤 후 재탐색** 을 누르세요. 분석 대상 탭으로 잠시 전환해 끝까지 스크롤한 뒤, 분석 화면으로 돌아와 새로 나타난 이미지만 추가합니다. 기존 선택 상태는 그대로 유지됩니다.

### 필터·정렬·선택

- 최소 너비/높이(px), 최소 파일 크기(KB/MB), 형식(JPEG·PNG·WEBP·GIF·SVG·AVIF 등), 썸네일 의심 제외, 확인 필요만 보기
- **크기 미확인 포함**: 서버가 파일 크기를 알려주지 않은 이미지를 크기 필터에서 통과시킬지 정합니다. **미확인 크기 측정** 버튼으로 실제로 받아서 크기를 계산할 수 있습니다.
- 정렬: 발견 순서(기본), 너비, 높이, 해상도, 가로세로 비율, 파일 크기, 형식, URL, URL 숫자(보조)
- 선택: 체크박스, **Shift+클릭**으로 범위 선택, 모두 선택, 모두 해제, 필터 결과만 선택

## 3. 순차 보기 (원본 뷰어)

카드 이미지를 누르거나 **순차 보기 ▶** 를 누르면 원본을 한 장씩 크게 볼 수 있습니다. 순서는 파일명이 아니라 **현재 목록 순서**(발견 순서 또는 선택한 정렬)를 따릅니다.

| 키 | 동작 |
| --- | --- |
| ← / → (PageUp / PageDown) | 이전 / 다음 |
| Home / End | 처음 / 마지막 |
| Space | 현재 이미지 선택 / 해제 |
| D | 현재 이미지 다운로드 |
| F 또는 이미지 클릭 | 실제 크기 ↔ 화면 맞춤 |
| Esc | 닫기 |

- 상단에서 **썸네일 의심 제외**, **실패 시 자동 건너뛰기** 를 켤 수 있습니다.
- 불러오지 못한 이미지는 오류 메시지와 **다음 이미지로** 버튼이 나타납니다.
- **원본 후보** 를 펼치면 검사한 모든 주소와 출처, 실제 해상도, 실패 사유를 볼 수 있습니다.

## 4. 다운로드

- 저장 위치: `다운로드 폴더\Image Hunter\사이트명\` (설정에서 사이트별 폴더를 끌 수 있음)
- 파일명 규칙
  1. 서버가 알려준 파일명이 쓸 만하면 그대로 사용 (쿼리 문자열은 쓰지 않음)
  2. 없거나 쓸 수 없으면 `image_001`, `image_002` … 로 자동 생성
  3. 같은 이름이 겹치면 `이름_001`, `이름_002` … 를 붙임
  4. 이미 같은 이름의 파일이 있으면 **덮어쓰지 않습니다** (설정에서 바꿀 수 있음)
  5. 확장자는 실제 형식에 맞춥니다 (예: 내용이 WebP인 `.jpg` → `.webp`)
- **다운로드** 탭: 대기 · 진행 중 · 완료 · 실패 · 취소 상태와 진행률, 실패 사유(403, 404, 네트워크 오류 등)를 보여줍니다.
  - 항목별 재시도·취소, 실패 항목 일괄 재시도, 완료·취소 항목 정리
  - **실패 목록 내보내기**: 실패한 URL을 `.txt` 파일로 저장하고 클립보드에 복사합니다. 그대로 **URL 붙여넣기** 화면에 붙여 다시 시도할 수 있습니다.
- 외부 링크를 막는 사이트(403)는 원래 페이지 주소를 Referer로 붙여 한 번 더 내려받습니다.

## 5. URL 붙여넣기

페이지 분석 없이 이미지 주소 목록만으로 내려받습니다. 분석 화면의 **URL 붙여넣기** 탭을 엽니다.

```
https://example.com/images/photo1.jpg
https://example.com/images/photo2.png  표지.png
# 으로 시작하는 줄은 무시됩니다
```

1. 한 줄에 하나씩 URL을 붙여넣습니다. URL 뒤에 공백과 이름을 쓰면 그 파일명으로 저장합니다.
2. **목록 확인**: 형식 검사, 중복 제거 후 각 주소의 미리보기와 다운로드 가능 여부(해상도·형식·크기)를 확인합니다.
3. 표에서 파일명을 바로 고칠 수 있습니다. 비워두면 자동 파일명을 씁니다.
4. **선택 다운로드** 또는 **전체 다운로드**
5. 실패한 항목은 **실패 항목 재시도** 와 **실패 목록 내보내기** 로 처리합니다.

- 지원 주소: HTTP/HTTPS 이미지 주소. 로그인이 필요한 사이트는 Chrome에서 먼저 로그인해 두면 쿠키가 함께 전송됩니다.
- 이미지가 아닌 **웹페이지 주소**를 넣으면 "웹페이지 주소입니다"로 표시되며, **이 페이지 분석** 을 누르면 그 페이지를 열어 분석 화면으로 이어갑니다.
- Referer 칸을 비우면 각 이미지 사이트의 주소를 Referer로 사용합니다.

## 7. 문제 해결

| 증상 | 해결 |
| --- | --- |
| "분석할 수 없는 페이지입니다" | `chrome://` 페이지, Chrome 웹 스토어 등은 확장 프로그램이 접근할 수 없습니다. `file://` 페이지는 `chrome://extensions` → Image Hunter → **파일 URL에 대한 액세스 허용** 을 켜세요. |
| 스크롤해야 나오는 이미지가 빠짐 | **스크롤 후 재탐색** 을 누르세요. 여러 번 눌러도 새 이미지만 추가됩니다. |
| 다운로드할 때마다 저장 위치를 묻는 창이 뜸 | Chrome 설정 → 다운로드 → **다운로드 전에 각 파일의 저장 위치 확인** 을 끄세요. |
| 403 접근 거부 | 설정에서 Referer 지정을 켜고 다시 시도하세요. 로그인이 필요한 사이트는 먼저 로그인하세요. |
| 파일 크기가 표시되지 않음 | 서버가 크기를 알려주지 않은 경우입니다. **미확인 크기 측정** 으로 확인할 수 있습니다. |

> 다운로드한 이미지의 저작권은 원저작자에게 있습니다. 개인적인 용도로, 사이트 이용 약관을 지켜 사용하세요.
