# Image Hunter 설치 및 사용 설명서 (v1.3.1)

웹페이지의 이미지를 페이지 순서대로 추출하고, 원본 후보를 확인해서 일괄 다운로드하거나 PDF로 저장하는 Chrome 확장 프로그램입니다. 서버 없이 내 PC에서만 동작합니다.

- 지원 환경: Windows 11, Chrome 116 이상 (Manifest V3)
- 외부 서버로 보내는 데이터 없음

---

## 1. 설치

1. `image-hunter-1.3.1.zip`의 압축을 풉니다. 예: `C:\image-hunter-1.3.1\`
   이 폴더 바로 안에 `manifest.json`이 있어야 합니다(`docs\` 폴더에는 설명서와 테스트 결과가 있습니다).
2. Chrome 주소창에 `chrome://extensions` 를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다** 를 누르고 `C:\image-hunter-1.3.1` 폴더를 선택합니다.
   - "매니페스트 파일이 없거나 읽을 수 없습니다" 오류가 나면, 고른 폴더 안에 `manifest.json`이 바로 보이는지 확인하세요. 압축 프로그램이 폴더를 한 겹 더 만들었다면 그 안쪽 폴더를 고릅니다.
5. 툴바의 퍼즐 아이콘에서 **Image Hunter** 옆 핀을 눌러 고정합니다.

> 압축을 푼 폴더를 지우거나 옮기면 동작하지 않습니다. 업데이트할 때는 같은 폴더에 새 파일을 덮어쓴 뒤 `chrome://extensions`에서 새로고침(↻)을 누르세요.
> 1.0.0에서 업데이트하면 권한이 줄어듭니다(모든 사이트 상시 접근 → 메뉴를 연 탭만). 필요하면 설정에서 모든 사이트 접근을 다시 허용할 수 있습니다.

## 2. 시작하기

툴바의 Image Hunter 아이콘을 누르거나 **Alt + Shift + I** 를 누르면 메뉴가 열립니다.

| 메뉴 | 동작 |
| --- | --- |
| 이 페이지의 이미지 찾기 | 현재 탭의 이미지를 찾아 새 탭에 목록을 엽니다 |
| 이미지 URL 직접 입력 | URL 목록으로 바로 다운로드합니다 |
| 연속 PDF 만들기 | 주소의 번호를 바꿔가며 여러 페이지를 차례로 PDF로 저장합니다 (현재 페이지 주소가 채워짐) |
| 다운로드 현황 | 진행률, 실패 사유, 재시도, 결과 내보내기 |
| 설정 | 저장 폴더, 파일명 충돌 처리, PDF 구성, 선택 권한 |

## 3. 페이지 이미지 목록

모든 이미지가 **페이지에 나타난 순서대로** 한 목록에 표시됩니다. 카드 오른쪽 위의 `#번호`가 발견 순번입니다. 파일명·해상도·URL로 다시 정렬하지 않습니다.

### 카드에 표시되는 정보

- 미리보기, 발견 순번, 해상도와 종횡비(예: `1920 × 1280 · 3:2`), 확장자, 파일 크기
- 확인하지 못한 값은 추정하지 않고 **"확인 불가"** 로 표시합니다. 확장자를 URL로만 짐작한 경우에는 `PNG (추정)`처럼 표시합니다.
- **원본 상태**

| 상태 | 뜻 |
| --- | --- |
| 원본 후보 확인 | 실제 파일을 확인했고, 찾은 후보 중 가장 큽니다 |
| 고해상도 후보 | 화면에 보이는 것보다 큰 버전(srcset, 링크 등)을 찾아 확인했습니다 |
| 후보 비교 필요 | 작거나(썸네일 의심), 모양이 다른 더 큰 후보가 있어 직접 확인이 필요합니다 |
| 확인 불가 | 이미지 파일에 접근할 수 없어 확인하지 못했습니다 |

- 후보가 둘 이상이면 카드에 **후보 선택 상자**가 나타납니다(해상도 · 출처 · 파일명). 고르면 그 URL로 다운로드하고, 상태에 "(직접 선택)"이 붙습니다.
- 찾은 출처: `srcset`, `링크`, `고해상도 속성`(data-*), `지연 로딩 속성`, `CSS 배경` 등
- 잘못된 URL, `javascript:`, `blob:` 이미지는 점선 카드로 사유를 보여주며 선택할 수 없습니다.
- 같은 URL이 여러 번 나오면 처음 나온 항목 하나만 표시합니다(쿼리 문자열이 다르면 다른 이미지로 봅니다).

### 검색

목록을 열면 페이지를 끝까지(최대 30화면) 스크롤하며 이미지를 찾고, **썸네일 의심 제외**, **JPG만**, **최소 너비 500 · 높이 400** 필터가 켜진 상태로 보여줍니다. 다른 형식도 보려면 확장자 칩을 누르세요. 기본값은 설정 → "이미지 목록을 열 때"에서 바꿀 수 있습니다.


- **다시 검색**: 현재 페이지를 다시 확인합니다. 새로 생긴 이미지는 페이지 안 위치에 들어가고, 기존 항목의 순서와 선택은 그대로입니다.
- **스크롤하며 추가 검색**: 페이지 탭으로 잠깐 전환해 아래로 스크롤하면서 지연 로딩 이미지를 불러온 뒤 돌아옵니다. 한 번에 최대 30화면(설정에서 변경)까지만 스크롤하고, 스크롤 위치는 원래대로 돌려놓습니다. 다시 누르면 멈춘 곳부터 이어서 확인합니다.
- 탭이 다른 페이지로 이동했으면 목록을 새로 만들고 안내합니다. 진행 중이거나 끝난 다운로드는 그대로 둡니다.

### 미리보기 크기·필터·선택

- **미리보기**: 작게 / 중간(기본) / 크게. 카드 크기만 바뀌고 순서, 선택, 필터는 그대로입니다. 마지막 선택을 기억합니다.
- **필터**: 최소 너비·높이(px), 최소 파일 크기(KB/MB), 크기 확인 불가 항목 표시/숨김, 확장자, 원본 상태, 썸네일 의심 제외. 필터는 보이는 항목만 바꾸고 데이터와 선택은 지우지 않습니다. 잘못된 값(음수, 문자)은 빨간색으로 표시하고 무시합니다.
- **선택**: 체크박스나 미리보기 클릭, Shift+클릭으로 범위 선택, **모두 선택**(숨겨진 항목 포함), **모두 해제**, **표시된 항목만 선택**. 필터를 바꿔도 선택은 유지되지만, **다운로드와 PDF에는 화면에 표시된 선택 항목만** 들어갑니다. 숨겨진 선택 수는 따로 보여줍니다.
- **키보드**: 목록에서 방향키로 이동, Space로 선택·해제, Enter로 원본을 새 탭에서 열기
- **크기 확인**: 서버가 파일 크기를 알려주지 않은 항목을 실제로 받아서 크기를 계산합니다.

## 4. 다운로드

**선택 다운로드 (N)** 를 누르면 선택한 이미지가 페이지 순서대로 대기열에 들어갑니다.

- 저장 위치: `다운로드 폴더\ImageHunter\페이지 제목\` (설정에서 사이트별, 하위 폴더 없음으로 바꿀 수 있음). 실제 다운로드 폴더 위치는 Chrome 설정에 따라 다릅니다.
- 파일명
  1. 서버나 URL이 알려준 파일명을 그대로 씁니다(쿼리 문자열은 쓰지 않음).
  2. 파일명을 알 수 없으면 `페이지 제목_순번.확장자`로 정합니다. 예: `갤러리_012.jpg`
  3. 다른 URL인데 이름이 같으면 `photo (1).jpg`, `photo (2).jpg` …로 저장해 하나도 잃지 않습니다.
  4. 같은 이름의 파일이 폴더에 이미 있으면 덮어쓰지 않습니다(설정에서 변경 가능).
  5. Windows에서 쓸 수 없는 문자는 `_`로 바꿉니다.
- 이미 받은 이미지는 다시 선택해도 내려받지 않습니다.
- 동시에 3개씩(설정에서 1~8) 내려받습니다.

### 다운로드 탭

| 상태 | 뜻 |
| --- | --- |
| 대기 | 순서를 기다리는 중 |
| 진행 중 | 내려받는 중. Chrome이 크기를 알려줄 때만 % 표시 |
| 완료 | 저장됨 |
| 실패 | 사유 표시. 예: 접근 거부 (403), 서버가 파일을 제공하지 않음 (404 등), 네트워크 오류 |
| 취소 | 사용자가 취소함 |

- 항목별 **재시도 / 취소**, **실패 항목 재시도**(실패한 것만), **전체 취소**, **완료·취소 항목 정리**
- **결과 CSV / 결과 JSON**: 원본 URL, 다운로드 URL, 파일명, 너비·높이, 확장자(추정 여부), 상태, 오류, 시작·완료 시각. CSV는 Excel에서 한글이 깨지지 않게 저장합니다.
- **실패 URL 목록**: 실패한 URL을 `.txt`로 저장하고 클립보드에 복사합니다. "URL 직접 입력"에 그대로 붙여 다시 시도할 수 있습니다.
- Chrome이 확장 프로그램 백그라운드를 잠시 멈춰도, 진행 중이던 다운로드를 다시 찾아 끝까지 추적합니다.

## 5. PDF로 저장

선택한 이미지를 **목록 순서대로 PDF 한 파일**에 넣습니다. 웹툰이나 만화 페이지를 묶을 때 유용합니다.

1. 이미지를 선택하고 **PDF로 저장 (N)** 을 누릅니다.
2. 진행률이 표시되고, 끝나면 `ImageHunter\페이지 제목\페이지 제목.pdf`로 저장됩니다.

- JPEG은 다시 압축하지 않고 그대로 넣어 화질이 떨어지지 않습니다. PNG·WebP·GIF 등은 무손실로 넣습니다(투명한 부분은 흰색).
- **PDF 구성**(PDF 버튼 옆에서 고르거나 설정에서 지정)
  - **이어 붙이기**(기본): 이미지 사이에 빈틈 없이 위아래로 붙입니다. 웹툰처럼 세로로 이어 보는 데 맞습니다. PDF 한 쪽의 최대 길이(약 5m) 때문에 긴 회차는 몇 쪽으로 나뉘며, 쪽은 이미지 경계에서만 나뉩니다.
  - **이미지마다 한 쪽**: 이미지 하나가 PDF 한 쪽입니다.
  - **A4**: 이미지마다 A4 한 쪽에 맞춥니다.
- PDF에는 **선택했고 지금 화면에 표시된** 이미지만 들어갑니다. 필터로 숨긴 이미지는 선택해 두었어도 넣지 않습니다(다운로드도 같음).
- 웹툰처럼 이미지가 별도 이미지 서버(CDN)에 있으면, 기본 권한으로는 그 이미지 데이터를 읽을 수 없습니다. 이때는 PDF를 바로 저장하지 않고 두 가지 중에서 고르게 합니다.
  - **〈이미지 서버〉 접근 허용 후 다시 만들기**: Chrome 권한 창에서 그 서버만 허용하면 전체를 다시 만듭니다. 모든 사이트를 허용할 필요는 없습니다.
  - **제외하고 저장 (N장)**: 읽을 수 있는 이미지만으로 저장합니다.
- 사이트가 거부한 이미지(403 등)는 빼고 사유를 보여줍니다. 허용한 서버 권한은 설정 → 사이트 접근 권한에서 해제할 수 있습니다.
- 페이지 안의 배너·광고도 이미지이므로, 회차 이미지만 넣으려면 먼저 **최소 너비/높이** 필터(예: 600px)를 걸고 **표시된 항목만 선택**을 누르세요.
- URL 직접 입력 화면에서도 선택한 URL로 PDF를 만들 수 있습니다.

## 6. 연속 PDF (여러 회차를 PDF로)

웹툰 회차처럼 **주소의 번호만 바뀌는 페이지들**을 차례로 열어 각각 PDF로 저장합니다.

1. 회차 하나의 주소를 **주소** 칸에 붙여넣습니다. 메뉴의 **연속 PDF 만들기**로 열면 현재 페이지 주소가 들어 있습니다.
   예: `https://comic.naver.com/webtoon/detail?titleId=821597&no=116&week=tue`
2. **바꿀 부분**에서 바뀌는 번호를 고릅니다. 회차 번호로 보이는 `no=116`, 또는 경로의 마지막 숫자(`/webtoon/123/4567` → `4567`)가 먼저 선택되어 있습니다.
3. **시작 · 끝 · 간격**을 정합니다. 예: 시작 100, 끝 116 → 17개 주소. 아래에 첫 주소와 마지막 주소가 미리 보입니다.
   - 범위에 제한이 없습니다. 번호가 듬성듬성한 사이트도 그냥 넓게 잡으면 됩니다. 없는 주소는 확인 후 건너뜁니다(아래 참고).
   - **끝**을 비워두면 끝 없이 진행하고, 없는 주소가 **연달아 N번**(기본 10) 나오면 멈춥니다.
4. 필터와 옵션을 확인합니다.
   - 최소 너비 **500**, 최소 높이 **400**, **JPG만**, **썸네일 의심 제외**, **스크롤하며 추가 검색**이 기본으로 켜져 있습니다.
   - PDF 구성(기본: 이어 붙이기), 하위 폴더, 페이지 사이 대기(기본 2초)
5. **시작**을 누릅니다.
   - 처음 한 번 그 사이트(예: comic.naver.com) **접근 허용** 창이 뜹니다. 페이지를 자동으로 열려면 필요합니다.
   - 이미지가 다른 서버(예: image-comic.pstatic.net)에 있으면 첫 페이지에서 멈추고 **접근 허용 후 계속**을 묻습니다. 허용하지 않으면 그 이미지를 뺀 채 계속합니다.
6. 각 주소가 차례로 열렸다가 닫히며, 표에 상태(페이지 여는 중 → 스크롤 → 원본 확인 → PDF → 완료), 넣은 이미지 수, 파일 이름이 표시됩니다.
   - 저장 위치: `다운로드\ImageHunter\(하위 폴더)\페이지 제목.pdf`
   - **없는 주소 확인**: 탭을 열기 전에 주소를 한 번 요청해 HTTP 오류(404 등), 다른 페이지로 이동(예: 없는 회차 → 작품 목록), "찾을 수 없습니다 / 존재하지 않는 / not found / 아직 공개되지 않았습니다" 같은 페이지인지 확인합니다. 그렇다면 탭을 열지 않고 **없음**으로 넘어갑니다. 없는 주소는 표에서 기본으로 숨기며, **없는 주소도 표에 표시**를 켜면 이유와 함께 볼 수 있습니다.
   - 페이지는 있지만 조건에 맞는 이미지가 없는 주소(로그인이나 결제가 필요한 회차 등)는 **건너뜀**으로 표시합니다.
   - **중지**는 지금 페이지까지만 처리합니다. **실패·건너뜀 다시**로 나머지를 다시 할 수 있습니다.

> 스크롤하는 동안 각 페이지 탭이 잠깐 앞에 나왔다가 Image Hunter 탭으로 돌아옵니다(백그라운드 탭에서는 지연 로딩 이미지가 불러와지지 않기 때문). 한 번에 한 주소씩 처리하고, 실제 페이지 사이에는 설정한 시간(기본 2초), 없는 주소 사이에는 0.3초를 기다려 사이트에 부담을 주지 않도록 했습니다. 범위가 넓으면 없는 주소 확인에만 시간이 걸릴 수 있습니다(1,000개 ≈ 5~10분). 로그인·결제가 필요한 회차는 우회하지 않습니다.

## 7. URL 직접 입력

```
https://example.com/images/photo1.jpg
https://example.com/images/photo2.png  표지
# 으로 시작하는 줄은 무시됩니다
```

1. 한 줄에 하나씩 URL을 붙여넣거나 **TXT/CSV 불러오기**를 누릅니다(CSV: `url,filename`).
2. **목록 확인**: 앞뒤 공백 제거, 빈 줄 무시, HTTP/HTTPS 검사, 중복 제거. 잘못된 줄은 줄 번호와 사유를 보여줍니다.
3. 표는 **입력한 순서 그대로**이며, 각 URL을 불러올 수 있는지, 해상도·형식·크기는 얼마인지 보여줍니다. 파일명 칸을 비우면 `image_001`처럼 입력 순번으로 이름을 정합니다.
4. **선택 다운로드 / 전체 다운로드 / PDF로 저장**. 저장 위치는 `ImageHunter\직접 입력\`(하위 폴더 이름 변경 가능)입니다.
5. **실패 항목 재시도, 실패 목록 내보내기, 목록 TXT / 목록 CSV**

- 웹페이지 주소(이미지가 아님)를 넣으면 그렇다고 알려줍니다. 그 페이지를 열고 메뉴에서 "이 페이지의 이미지 찾기"를 누르세요.
- 로그인이 필요한 사이트는 Chrome에서 먼저 로그인하면 받을 수 있는 경우가 있습니다. 사이트가 거부하면 실패 사유를 보여줍니다.

## 9. 권한과 사이트별 제한

- 기본 권한은 **메뉴를 연 탭에만 일시적으로 접근**(`activeTab`)입니다. 탭이 다른 페이지로 이동하면 권한이 사라지므로, 그 페이지에서 메뉴를 다시 여세요.
- **모든 사이트 접근(선택)** 을 허용하면 다른 사이트(CDN) 이미지의 파일 크기·형식 확인, PDF 포함, 다른 사이트 iframe 추출이 가능해집니다. 설정에서 언제든 해제할 수 있습니다.
- Image Hunter는 **로그인, 핫링크 방지, 사이트 보안 정책을 우회하지 않습니다.** 정상적으로 접근할 수 있는 이미지만 받고, 실패하면 사유를 보여줍니다.
- `blob:` 이미지는 그 페이지 안에서만 유효해서 받을 수 없습니다.
- Chrome 내부 페이지(`chrome://`), Chrome 웹 스토어는 분석할 수 없습니다. `file://` 페이지는 `chrome://extensions` → Image Hunter → 세부정보 → **파일 URL에 대한 액세스 허용**을 켜야 합니다.

## 10. 문제 해결

| 증상 | 해결 |
| --- | --- |
| "이 탭에 접근할 수 없습니다" | 탭이 이동했거나 Chrome이 막는 페이지입니다. 해당 페이지에서 메뉴를 다시 여세요. |
| 스크롤해야 나오는 이미지가 빠짐 | **스크롤하며 추가 검색**을 누르세요. 여러 번 누르면 이어서 확인합니다. |
| 파일 크기가 "크기 확인 불가" | 다른 사이트 이미지이거나 서버가 크기를 알려주지 않은 경우입니다. **크기 확인** 버튼을 누르거나 설정에서 모든 사이트 접근을 허용하세요. |
| PDF에서 일부 이미지가 빠짐 | 진행 영역의 제외 사유를 확인하세요. 대부분 다른 사이트 이미지의 권한 문제입니다. |
| 403 접근 거부 | 사이트가 외부 다운로드를 막았습니다. Image Hunter는 이를 우회하지 않습니다. |
| 저장할 때마다 위치를 묻는 창이 뜸 | Chrome 설정 → 다운로드 → **다운로드 전에 각 파일의 저장 위치 확인**을 끄세요. |

> 다운로드한 이미지의 저작권은 원저작자에게 있습니다. 개인적인 용도로, 사이트 이용 약관을 지켜 사용하세요.
